The Problem & The Solution

Every time you ask Copilot a question, it burns through requests reading your files. wRag gives it instant access to pre-indexed answers.

❌ Without wRag

You: "How does auth work?"

Copilot behind the scenes:
 → Read project structure
 → Search for "auth" in files
 → Read Auth/Provider.php
 → Read Auth/TokenManager.php
 → Read config/auth.yaml
 → Search for related tests
 → Read Confluence docs

= 7 requests consumed

✅ With wRag

You: "How does auth work?"

Copilot behind the scenes:
 → wRag search_code("auth")
   ← Provider.php, TokenManager.php,
     auth.yaml snippets returned
 → wRag search_docs("auth flow")
   ← Confluence section returned

= 2 requests consumed (70% saved)

How It Works

Three simple steps — all running on your machine.

1

Index

wRag reads your code and docs, breaks them into smart chunks (functions, classes, sections), and stores them with semantic embeddings.

2

Serve

A tiny local MCP server runs in the background. Copilot discovers it automatically via VS Code configuration.

3

Query

When you ask Copilot anything, it calls wRag first to find relevant code — instead of scanning files one by one.

Quick Start

Up and running in under 5 minutes.

1. Install

git clone https://github.com/pankaj-raundal/wrag.git
cd wrag
python -m venv .venv
source .venv/bin/activate
pip install -e .

2. Register & Index Your Project

wrag add myproject /path/to/your/project
wrag index myproject

3. Connect to VS Code Copilot

Copy .vscode/mcp.json to your project, or add globally:

{
  "servers": {
    "wrag": {
      "type": "stdio",
      "command": "wrag",
      "args": ["serve"]
    }
  }
}

4. (Optional) Auto-Reindex on Changes

wrag watch

Key Features

🧠 Language-Aware Chunking
Splits code at function/class boundaries using tree-sitter. Supports Python, PHP, JS/TS, Markdown, YAML.
📄 Confluence Integration
Indexes entire Confluence spaces. Copilot can answer questions from your team docs.
⚡ Incremental Indexing
Only re-processes files that actually changed (SHA-256 tracking). Second run takes seconds.
👁️ File Watcher
Watches your workspace and automatically re-indexes when files change. Always up to date.
🔒 100% Local
All embeddings run on your CPU. No code leaves your machine. No external API keys required.
🚀 Fast Search
Vector search returns results in under 100ms. Copilot gets answers instantly.
